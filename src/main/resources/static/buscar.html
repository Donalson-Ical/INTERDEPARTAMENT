Buscar Jugador

Tres modos de búsqueda, cada uno usando una estructura de datos distinta.

Árbol AVL — O(log n)

Buscar por ID

Utiliza el árbol AVL autobalanceado. La búsqueda está garantizada en O(log n) — con 1,000 jugadores solo necesita hasta 10 comparaciones.

Tabla Hash — O(1) promedio

Buscar por nombre exacto

Utiliza la tabla hash con encadenamiento. El nombre se convierte en un índice mediante una función hash polinomial y la búsqueda es en tiempo constante promedio.

Lista enlazada — O(n)

Búsqueda parcial por nombre

Recorre la lista enlazada nodo a nodo buscando coincidencias parciales sin distinguir mayúsculas. Útil cuando no se sabe el nombre completo. Retorna todos los resultados que contengan el texto buscado.
